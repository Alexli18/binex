The Problem

AI agent frameworks are a black box

When your agent pipeline fails at 3 AM, you need answers — not abstractions.

Cloud lock-in

Your prompts, data, and agent logic live on someone else's servers. No audit trail, no export, no self-hosting.

Black-box agents

When a 5-agent chain produces garbage, you have no idea which agent went wrong or why. No trace, no diff, no replay.

No engineering primitives

Print statements are your only debugging tool. No version control for workflows, no cost tracking, no replay. That's not engineering.

Binex gives you full control

100% Local

Everything runs on your machine. Your data stays yours. No API keys sent to intermediaries.

Full observability

Every prompt, response, cost, and timing recorded. Trace the full execution graph. Debug any node.

Node-level replay

Found the broken node? Swap the model and re-run just that node. No re-running the whole pipeline.

Quickstart

Up and running in 60 seconds

No accounts. No API keys for Binex. Just install and go.

1

Install and launch

terminal 
$ pip install binex
$ binex hello        # zero-config demo
$ binex ui           # visual editor at localhost:8340
2

Define your workflow

research.yaml 
name: research-pipeline
nodes:
  researcher:
    agent: llm://openai/gpt-4o
    prompt: "Research {topic} and provide key findings"
  analyst:
    agent: llm://anthropic/claude-sonnet-4-20250514
    prompt: "Analyze these findings: ${node.researcher.output}"
    depends_on: [researcher]
  reviewer:
    agent: human://approve
    depends_on: [analyst]
3

Run, debug, iterate

terminal 
$ binex run research.yaml --var topic="AI safety"
Run 8f4a21c completed (3 nodes, $0.089, 8.0s)

$ binex debug 8f4a21c    # inspect every node
$ binex explore 8f4a21c  # interactive dashboard
$ binex diff 8f4a21c 3b2c19d  # compare two runs
