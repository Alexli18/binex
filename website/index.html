AI agent frameworks are a black box

When your agent pipeline fails at 3 AM, you need answers — not abstractions.

Cloud Lock-in

Your prompts, data, and agent logic live on someone else's servers. You can't audit, export, or self-host.

Black-box Agents

When a chain of 5 agents produces garbage, you have no idea which agent went wrong, or why.

No Debugging

No trace, no diff, no replay. Print statements are your only debugging tool. That's not engineering.

Binex gives you full control

100% Local

Everything runs on your machine. Your data stays yours. No API keys sent to intermediaries.

Full Observability

Every prompt, response, cost, and timing — recorded. Debug any node. Trace the full execution graph.

Node-level Replay

Found the broken node? Swap the model or prompt and re-run just that node. No re-running the whole pipeline.

Everything you need to ship reliable agents

From workflow authoring to post-mortem debugging — one tool, no cloud.

DAG Orchestration

YAML-first workflow definition with visual drag & drop editor. 6 node types, conditional execution, fan-out/fan-in patterns.

  • LLM, Local, Human, A2A agents
  • Visual + YAML sync both ways
  • 18 preset patterns (diamond, map-reduce...)

Full Debuggability

Inspect every node's input, output, prompt, and timing. Trace execution with Gantt timelines. Diff between runs.

  • Debug, Trace, Diagnose, Lineage
  • Bisect to find divergence point
  • Replay individual nodes

Cost Tracking

Real-time cost estimation as you build. Per-node cost breakdown. Budget limits with stop/warn policies.

  • Per-node cost breakdown
  • Budget limits (stop or warn)
  • 40+ providers via LiteLLM

Visual Web UI

18-page dashboard with editor, debug, trace, and comparison tools

Human-in-the-Loop

Input, approval, and output nodes for human oversight in agent pipelines

Framework Adapters

LangChain, CrewAI, AutoGen — use your existing agents as Binex nodes

A2A Protocol

Agent-to-Agent gateway for multi-service orchestration across networks

Up and running in 60 seconds

No accounts. No API keys for Binex. Just install and go.

1

Install & launch

bash 
$ pip install binex
$ binex hello        # zero-config demo
$ binex ui           # opens visual editor at localhost:8340
2

Define your workflow

workflow.yaml 
name: research-pipeline
nodes:
  researcher:
    agent: llm://openai/gpt-4o
    prompt: "Research {topic} and provide key findings"
  analyst:
    agent: llm://anthropic/claude-sonnet-4-20250514
    prompt: "Analyze these findings: ${node.researcher.output}"
    depends_on: [researcher]
  reviewer:
    agent: human://approve
    depends_on: [analyst]
3

Run, debug, iterate

bash 
$ binex run workflow.yaml --var topic="AI safety"
Run abc123 completed (3 nodes, $0.042, 12.3s)

$ binex debug abc123    # inspect every node
$ binex trace abc123    # Gantt timeline
$ binex diff abc123 def456  # compare two runs
